# Free Image Compressor

A fast, private, and completely free online image compressor that runs entirely in your browser.

## Features

- **100% Private** — All processing happens locally in your browser. Your images never leave your device.
- **Lightning Fast** — Compress images instantly using your device's native capabilities.
- **Completely Free** — No subscriptions, no credit cards, no limits.
- **Multiple Formats** — Supports JPEG, PNG, WebP, BMP, GIF, and AVIF.
- **Adjustable Quality** — Fine-tune compression with the quality slider.
- **Max Dimensions** — Resize images to specific widths while maintaining aspect ratio.
- **Size Targets** — Set a maximum file size and the compressor will find the best quality that fits.

## How to Use

1. Drop an image file onto the drop zone or click to browse
2. Adjust quality, max width, output format, and max size settings
3. Click "Compress Image" (or press Enter)
4. Preview the original vs compressed image
5. Download the compressed file

## Tech Stack

- HTML5
- Tailwind CSS (via CDN)
- Vanilla JavaScript (no frameworks)
- Canvas API for image compression
